1. Do not overcomplicate the solution. Keep it as minimal as possible.
2. Avoid excessive comments; it should be one or two lines at most.
3. Always refer to the latest official documentation before applying the changes.
4. Always print the commands before executing them or prompt the user to run it.
5. If there are any questions, doubts, or gaps in the thought process, pause and clarify with the user before making assumptions.
